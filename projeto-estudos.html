Quorbe

Plataforma de estudos

Uma aplicação web criada para reunir recursos de organização e acompanhamento das atividades acadêmicas em um único ambiente.

HTML · CSS · JavaScript
01
Visão geral

Organização acadêmica em um único ambiente.

O Quorbe foi desenvolvido como uma plataforma de estudos voltada para alunos e professores. A proposta reúne recursos para organização e acompanhamento das atividades acadêmicas.

02
O problema

Tornar a rotina acadêmica mais organizada.

A plataforma busca centralizar diferentes atividades acadêmicas em um único ambiente, facilitando o acompanhamento da rotina de estudos.

03
A solução

Uma plataforma para organizar, acompanhar e estudar.

O Quorbe reúne funcionalidades para gerenciamento de tarefas, turmas, grupos de estudo e notas, além de recursos de gamificação para tornar a experiência mais envolvente.

04
Interface

Do planejamento à interface.

O projeto envolveu a elaboração de fluxos de telas, wireframes e protótipo interativo para estruturar a experiência da plataforma.

05
Tecnologias

HTML · CSS · JavaScript

Tecnologias utilizadas no desenvolvimento da interface web do projeto.
