## 📝 Sobre o Projeto

Este projeto consiste no desenvolvimento do meu **Portfólio Profissional**, criado na disciplina de **Desenvolvimento de Interfaces Web (DIW)** do curso de **Ciência da Computação na PUC Minas**.

O objetivo é apresentar minha trajetória acadêmica, conhecimentos técnicos, projetos desenvolvidos e evolução profissional em uma interface web organizada, responsiva e acessível.

### 👤 Sobre Mim

> **Olá, sou o Gustavo.**
>
> Sou estudante de **Ciência da Computação na PUC Minas** e estou construindo minha base no desenvolvimento de software a partir da prática, dos fundamentos da computação e de projetos acadêmicos.
>
> **Como eu trabalho e aprendo:**
>
> Tenho uma abordagem prática e investigativa. Quando encontro um problema ou bug no código, busco entender a causa e a lógica por trás da solução, em vez de recorrer apenas a respostas prontas. Enxergo cada erro como parte natural do processo de aprendizado e consolidação técnica.
>
> **Tecnologias e Ferramentas:**
>
> - **Fundamentos e Back-end:** prática com **C, C++ e Java**, aplicando conceitos de Algoritmos, Estruturas de Dados, Engenharia de Software e Banco de Dados.
> - **Front-end e UX/UI:** estruturação de interfaces com **HTML5 e CSS3**, além de prototipagem e planejamento visual no **Figma e Miro**.
> - **Fluxo de Trabalho:** uso de **macOS e Terminal** para compilação e execução de projetos, **VS Code**, versionamento com **Git/GitHub** e simulação no **Tinkercad** para projetos com Arduino/IoT.
>
> **Colaboração e Projetos:**
>
> Acredito que um bom projeto vai além do código. Valorizo a **comunicação clara, organização de tarefas e documentação bem estruturada**. Já participei do desenvolvimento de soluções em equipe, como um sistema de monitoramento de enchentes com Arduino e a prototipagem de uma plataforma educacional focada na experiência do usuário.
>
> **Objetivo:**
>
> Meu foco atual é evoluir minhas habilidades técnicas a cada semestre, aplicar o conhecimento adquirido na faculdade em diferentes desafios e me preparar para minhas primeiras oportunidades no mercado de tecnologia.

## ✨ Funcionalidades Principais

- 👤 **Apresentação Pessoal:** seção "Sobre Mim" apresentando minha formação, objetivos e competências técnicas.
- ⏳ **Linha do Tempo de Projetos:** apresentação cronológica dos principais trabalhos desenvolvidos, incluindo projetos acadêmicos e pessoais.
- 💼 **Seção de Experiências:** organização de atividades acadêmicas, projetos interdisciplinares, trabalhos em equipe e experiências relevantes.
- 📨 **Formulário de Contato:** espaço destinado ao contato profissional, juntamente com links para LinkedIn e GitHub.
- 📱 **Design Responsivo:** interface adaptada para diferentes tamanhos de tela, incluindo computadores, tablets e dispositivos móveis.
- 🎨 **Interface e Experiência do Usuário:** desenvolvimento de uma interface com foco em organização, usabilidade e apresentação visual.

## 🔧 Instalação e Execução

### Pré-requisitos

Para executar o projeto localmente, serão necessários:

- **Node.js** v18 ou superior
- **npm** ou **yarn**
- **Git**

### 📥 1. Clone o repositório

```bash
git clone https://github.com/gustavonmsouza/portfolio.git
```

### 📁 2. Acesse a pasta do projeto

```bash
cd portfolio
```

### 📦 3. Instale as dependências

```bash
npm install
```

### ▶️ 4. Inicie o servidor de desenvolvimento

```bash
npm run dev
```

### 🌐 5. Acesse o projeto

Após iniciar o servidor, acesse no navegador o endereço apresentado pelo terminal.

Normalmente:

```text
http://localhost:5173
```

ou

```text
http://localhost:3000
```
