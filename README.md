#### 📝 Sobre o Projeto

Este projeto consiste no desenvolvimento do meu **Portfólio Profissional**, criado na disciplina de **Desenvolvimento de Interfaces Web (DIW)** do curso de **Ciência da Computação na PUC Minas** (2º Semestre).

### 👤 Sobre Mim
&gt; **Olá, sou o Gustavo.**
&gt; 
&gt; Sou estudante de **Ciência da Computação na PUC Minas** (2º semestre) e estou construindo minha base no desenvolvimento de software a partir da prática, dos fundamentos da computação e de projetos acadêmicos.
&gt; 
&gt; **Como eu trabalho e aprendo:**
&gt; Tenho uma abordagem prática e investigativa. Quando encontro um problema ou bug no código, busco entender a causa raiz e a lógica por trás da solução, em vez de recorrer a respostas prontas. Enxergo cada erro como parte natural do processo de aprendizado e consolidação técnica.
&gt; 
&gt; **Tecnologias e Ferramentas:**
&gt; * **Fundamentos e Back-end:** Prática com **C, C++ e Java**, aplicando conceitos de Algoritmos, Estruturas de Dados, Engenharia de Software e Banco de Dados.
&gt; * **Front-end e UX/UI:** Estruturação de interfaces com **HTML5 e CSS3**, além de prototipagem e planejamento visual no **Figma e Miro**.
&gt; * **Fluxo de Trabalho:** Uso diário de **macOS e Terminal** para compilação e execução de projetos, **VS Code**, versionamento com **Git/GitHub** e simulação no **Tinkercad** (Arduino/IoT).
&gt; 
&gt; **Colaboração e Projetos:**
&gt; Acredito que um bom projeto vai além do código. Valorizo a **comunicação clara, organização de tarefas e documentação bem estruturada**. Já atuei no desenvolvimento de soluções completas em equipe — como um sistema de monitoramento de enchentes com Arduino e a prototipagem de uma plataforma educacional focada na experiência do usuário.
&gt; 
&gt; **Objetivo:**
&gt; Meu foco atual é evoluir minhas habilidades técnicas a cada semestre, aplicar o conhecimento da faculdade em desafios reais e me preparar para minhas primeiras oportunidades no mercado de tecnologia.

#### ✨ Funcionalidades Principais
* 👤 **Apresentação Pessoal:** Seção "Sobre Mim" detalhando formação, filosofia de aprendizado e competências técnicas.
* ⏳ **Linha do Tempo de Projetos:** Exibição cronológica dos principais trabalhos desenvolvidos (acadêmicos e pessoais), com descrição, tecnologias usadas, links para repositórios e demonstrações visuais.
* 💼 **Seção de Experiências:** Histórico de atividades acadêmicas, projetos interdisciplinares, trabalhos em equipe e eventos técnicos.
* 📨 **Formulário de Contato Direto:** Integração funcional para envio de e-mails via **EmailJS** e links diretos para LinkedIn e GitHub.
* 📱 **Design Responsivo:** Interface adaptada para navegação em dispositivos móveis, tablets e computadores.

#### 🔧 Instalação e Execução

##### Pré-requisitos
* **Node.js** (v18 ou superior)
* **npm** ou **yarn**
* **Git**

##### Passos para rodar localmente:
1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/portfolio.git
   cd portfolio

```

1. **Instale as dependências:**

```
npm install

```

1. **Inicie o servidor de desenvolvimento:**

```
npm run dev

```

1. Acesse no navegador em `http://localhost:5173` ou `http://localhost:3000`.
